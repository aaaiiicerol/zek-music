--------------------------------------------------------------------------------
LISTA DE ARQUIVOS CRIADOS
--------------------------------------------------------------------------------
1. WINDOWS.md
   - Guia passo a passo em portugues para compilar o Zek Music no Windows.
   - Contem instrucoes de instalacao do Rust, Inno Setup 6 e 7-Zip.
   - Explica como rodar o script compilar_windows.bat.
   - Explica como fazer git push e criar tag para disparar o GitHub Actions.

2. compilar_windows.bat
   - Script para Windows (batch) que automatiza a compilacao local.
   - Etapas executadas:
     a) Verifica se Rust e Cargo estao instalados.
     b) Compila o projeto com 'cargo build --release'.
     c) Detecta a versao no Cargo.toml.
     d) Verifica se o Inno Setup 6 esta instalado.
     e) Gera o instalador 'dist/ZekMusic-Setup.exe' via ISCC.exe.
     f) Gera a versao portatil 'ZekMusic-Windows-Portable-<versao>.zip'.

--------------------------------------------------------------------------------
LISTA DE ARQUIVOS MODIFICADOS
--------------------------------------------------------------------------------
3. .gitignore
   - Adicionadas as entradas:
       /dist
       /portable
   - Motivo: ignorar arquivos gerados pela compilacao Windows (instalador e
     versao portatil) no controle de versao do Git.

4. packaging/windows/zek-music.iss
   - Removido o parametro invalido 'RunOnceId: "IconCache"' da secao [Run].
   - Motivo: o Inno Setup 6 nao aceita 'RunOnceId' na secao [Run]; ele so e
     valido em [UninstallRun]. Esse erro impediava a geracao do instalador
     .exe tanto localmente quanto no GitHub Actions (workflow windows).

5. README.md
